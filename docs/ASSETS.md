# Artwork provenance

`public/worlds.webp` is original project artwork generated with the built-in ImageGen tool. It was converted from its original PNG to WebP for the app. No reference-poster pixels were embedded. The supplied reference informed the purple/black/gold palette, floating-world map, and illuminated game controls.

Final generation prompt:

> Use case: stylized-concept. Original game world background for OYO UNLOCKED PWA, landscape 1536x1024. Atmospheric isometric fantasy business-world map with exactly nine floating rocky islands arranged in a clear 3-column by 3-row grid. Every island has small original gold and obsidian architectural towers. Luminous violet bridges connect neighboring islands. Deep black and purple mountainous sky, drifting violet mist and distant silhouettes. Polished cinematic video game environment artwork, sophisticated richly detailed 3D fantasy rendering. All nine islands fully visible. Island centers approximately at x 20%, 50%, 80% and y 22%, 50%, 78%, with consistent spacing so interactive HTML markers can overlay the island centers. Elevated isometric view. Gold lit windows, dramatic violet ambient light, subtle white highlights. Purple, black, gold, white. Jagged floating dark rock bases, polished obsidian and brushed gold architecture. No text, logos, labels, UI, watermark, characters, or copyrighted characters.
